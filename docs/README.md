# Documentation

| file | what it covers |
|---|---|
| `USAGE.md` | install, configure models, run a first research question, what the gates say, and the honest gaps |
| `MODELS.md` | model names → endpoints: pools, failover, cooldown, credentials, dialects, and who decides |
| `DECISIONS.md` | the decision record: what was adopted from upstream, what was audited, what was rejected and why |
| `TRANSLATION.md` | the glossary-as-contract, the coupling rule, and what is still Russian |

Design history from upstream (plans, specs, its own site assets) was removed from this fork: it
described another harness's paths and is not used at runtime. It remains in `vendor/deepdive/` (see
`scripts/vendor_upstream.sh`) and in upstream's git history.
